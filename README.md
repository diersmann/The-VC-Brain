# The-VC-Brain

The VC Brain is a proposed data- and AI-driven platform for discovering founders, building evidence-backed profiles, and supporting venture sourcing, screening, diligence, and investment decisions.

## Status

Design phase. The repository does not yet contain application code, a selected technology stack, or executable setup and validation commands.

## Repository Layout

| Path | Purpose |
|---|---|
| [`AGENTS.md`](AGENTS.md) | Repository contract and safety rules for coding agents |
| [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) | Proposed systems, data flow, and scoring approaches |
| [`Problem_Statement.pdf`](Problem_Statement.pdf) | Original challenge brief and product requirements |

## Development

Agents should read `AGENTS.md` first. Setup, build, lint, and test commands will be documented there and here when the implementation stack is selected.
